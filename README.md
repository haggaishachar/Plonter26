# הפלונטר של הכנסת ה-26

מודל של תורת המשחקים לפלונטר הקואליציוני אחרי הבחירות לכנסת ה-26 (אוקטובר 2026):
גוש נתניהו 53, גוש האופוזיציה 48, המפלגות הערביות 19.

אפליקציית Streamlit שבה כל הפרמטרים החופשיים של המודל ניתנים לשינוי, וההעדפות של כל מפלגה
והתחזית מתעדכנות בהתאם.

## הרצה

```bash
pip install -r requirements.txt
streamlit run app.py
```

## המודל

- **משחק הצבעה משוקלל [61; מנדטים]**, עם מדדי הכוח Banzhaf ו-Shapley-Shubik.
- **תועלת של מפלגה מקואליציה:** תיקים (כלל גמסון), מרחק מדיניות על ארבעה צירים
  (ביטחון, דת ומדינה, יחס אישי לנתניהו, רפורמה משפטית), פרמיית ראשות ממשלה וקנסות על קווים אדומים.
- **נקודת אי-הסכמה:** בחירות חוזרות, כולל פרמיית ממשלת מעבר לליכוד.
- **העברות בין שותפות** (תיקים, תקציבים, חקיקה) ביעילות שניתן לקבוע.
- **מנגנון הרכבה:** מרכיבים לפי סדר, ופתרון הבארגיינינג של נאש לדירוג הקואליציות.

הקוד: `model.py` (המודל), `app.py` (הניווט בין הדפים), `ui.py` (סרגל הפרמטרים החופשיים וקטעים משותפים) ו-`views/` (הדפים). הדפים שתלויים בפרמטרים (המודל האינטראקטיבי, קווים אדומים, מי חושש מבחירות, מידע גולמי) מציגים את סרגל הפרמטרים. מרחב המדיניות והסבר המודל לא תלויים בהם.

המיקומים האידאולוגיים ומשקלי הקווים האדומים הם הנחות מודל, לא נתונים.
